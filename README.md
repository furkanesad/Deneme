# Japonca Defterlerim

Üç uygulama tek sayfada: 帳 Japonca Defterim (kelime, kanji), 旅 Tabi Kaiwa (seyahat konuşması), 変 Çekimler. Tamamen çevrimdışı çalışır. Ayrıntılar: [OFFLINE.md](OFFLINE.md).

## Telefona kurmak (internet gerekmez)
1. Telefonda https://furkanesad.github.io/Deneme/ adresini aç. iPhone: Safari, Android: Chrome.
2. iPhone: Paylaş → "Ana Ekrana Ekle". Android: menü → "Uygulamayı yükle".
3. Uygulamayı bir kez internetliyken aç ve yüklenmesini bekle. Sonra uçak modunda da çalışır.

## Bilgisayarda açmak
```
python3 -m http.server 8765
```
Sonra http://localhost:8765/ adresini aç. Mac'te `baslat.command` dosyasına çift tıklamak da yeter.
